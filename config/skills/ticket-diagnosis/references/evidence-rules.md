# 工单证据规则

## 证据等级

- A 级：工具直接返回的工单字段、数据库只读查询结果、带来源的附件内容、固定 Commit 下的代码。
- B 级：多个 A 级事实共同支持，但仍需人工或额外工具确认的推断。
- C 级：仅依据命名、经验或模型常识形成的假设，只能作为下一步调查方向。

## 冲突处理

当用户描述与工具事实冲突时，以工具返回的当前快照为准，并明确指出冲突。不同数据源冲突时，不自行选择有利证据；记录来源、时间和差异，要求进一步核实。

## 停止条件

满足任一条件就停止继续调用工具并输出 `inconclusive`：

1. 缺少目标工单或工具无法读取工单；
2. 后续调查所需依赖不可用；
3. 已达到任务预算或重复得到相同证据；
4. 下一步需要写入生产系统或超出当前只读权限。

## 代码调查触发条件

只有工单中存在可检索锚点时才进入代码调查，例如错误码、异常文本、模块名、接口名、类/函数名或明确版本。只有泛化业务现象时，先补充数据库、日志或附件证据。
