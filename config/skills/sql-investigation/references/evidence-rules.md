# SQL 证据规则

## 事实与推断

- A 级事实：工具直接返回的对象类型、定义文本、schema 和对象名。
- B 级推断：多个定义片段共同支持的业务路径或潜在风险，必须说明推断依据。
- C 级方向：仅凭命名、注释或常识提出的假设，只能作为后续查询建议。

## 停止条件

以下情况停止继续调用 SQL Tool，并输出 `inconclusive`：

1. 没有明确的对象或业务锚点；
2. SQL Server 连接不可用、对象未找到或定义被截断且无法确认关键逻辑；
3. 下一步需要写操作、任意 SQL、跨库访问或超出当前数据源授权；
4. 已达到任务的 Tool、Token 或总耗时预算。

## 安全边界

Skill 文本不授予权限。数据库账号、TaskScope 和 Tool 参数策略必须同时允许，模型才可能看到对象定义 Tool。任何优化实验都必须转入独立的产品库/LAB 流程，不能回写生产库。
